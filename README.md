# Proyecto Comentarista 🎙️✨

Asistente editorial inteligente de escritorio para redactar, perfeccionar y previsualizar publicaciones para **X (Twitter)** y redes sociales a partir de ideas, análisis y recursos multimedia locales.

---

## 🎯 Visión General

**Proyecto Comentarista** nace para eliminar la fricción entre tener una idea o dato analítico (como el precio de la electricidad o un gráfico de generación) y publicar un post impecable en X:
1. **Entrada de ideas en bruto**: Escribe lo que piensas sin preocuparte por la forma.
2. **Asistencia y refinamiento con IA**: Corrección ortográfica instantánea, ajuste de tono (analítico, divulgativo, conciso) y propuestas alternativas.
3. **Integración multimedia**: Vincula capturas, gráficos de energía o vídeos locales directamente al post.
4. **Simulador fiel de X**: Previsualización idéntica a la interfaz real de X con contador de caracteres inteligente.
5. **Copia en un solo clic**: Copia el texto y los medios al portapapeles o abre X directamente con el contenido precargado.

---

## 🛠️ Stack Tecnológico Propuesto

| Capa | Tecnología | Justificación |
|---|---|---|
| **Frontend & Interfaz** | Next.js / React (o Vite) | Renderizado reactivo, interactividad inmediata y fidelidad visual a la UI de X. |
| **Estilos (CSS)** | Vanilla CSS | Diseño premium, temas oscuro/claro, microanimaciones y máximo control sin dependencias superfluas. |
| **Backend Local** | Node.js / Next.js API Routes | Conexión con APIs de IA, lectura del sistema de archivos local y almacenamiento de historial. |
| **Integración con IA** | SDK de Google GenAI / Anthropic / OpenAI | Generación y corrección contextual de textos. |
| **Ejecución en Windows** | Script `.bat` de un clic | Inicio rápido sin necesidad de abrir terminales manualmente. |
